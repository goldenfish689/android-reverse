Android逆向路线（2026-9）

一、基础知识
1. APK结构：普通、加固、U3D与Cocos2d游戏APK。
2. DEX、SO（ELF）、ARSC、Manifest文件结构。
3. 工具：010 Editor、JADX-GUI、Apktool、IDA Pro、Binary Ninja。
4. 语言：Java/Kotlin、Smali、ARM64/ARM32、JavaScript。

二、系统与底层原理
1. APK安装加载机制、PackageManager。
2. DEX加载过程与ART原理。
3. SO加载过程与Linker机制。
4. Android系统源码。
5. 系统调用、驱动、文件系统、内存、进程地址空间。

三、代码修改与补丁
1. Smali与ARM汇编修改。
2. DEX与SO补丁。
3. 代码还原。

四、混淆与加固
1. Java、SO、字符串混淆。
2. 自定义DEX、SO格式与Linker。
3. Java2C、Java虚拟机VMP、SO虚拟机VMP、OLLVM。
4. 脱壳与加固。
5. 厂商对抗措施与APP加固底层逻辑。

五、签名与完整性
1. APK签名算法与机制。
2. 签名绕过。
3. 包名、签名、代码完整性检测绕过。

六、动态分析
1. Java与SO动态调试。
2. 调试工具、脚本、使用经验。
3. 栈回溯、跟踪调试、内存与寄存器。
4. 内存Dump、Hook。

七、运行环境
1. Root、模拟器、云手机、虚拟机、沙盒。
2. 自定义ROM、一键换机、多开。

八、网络与协议
1. 抓包、反抓包。
2. 加密。
3. 协议分析与Sign算法还原。

九、安全对抗
1. 设备指纹、环境检测、大数据风控。
2. 反调试、反代码、代码完整性检测。
3. 无障碍检测。
4. Magisk、LSPosed、Xposed、Frida检测。
5. IMEI白名单、型号、应用黑白名单、自动化框架检测。

1. APP爬虫、自动化、竞品分析、代码还原。
2. 游戏封包解包、插件、自动化。

4. 平台账号业务：起号、养号、出租号。
